# Student Workbook: Weekly Exercises

Write your answers in a notebook or in this document. Complete the **Build** tasks during the lesson and try the **Challenge** tasks if you finish early.

## Week 1 — First HTML page

### Try it
1. Create a file called `index.html`.
2. Add the standard HTML document structure.
3. Set the browser tab title to `My Portfolio`.
4. Add one `<h1>` heading.
5. Add two paragraphs about what your website will be about.

### Challenge
- Add an `<h2>` called `My Interests`.
- Add a list of three interests.
- Add a second `<h2>` called `What I Want to Learn`.

### Checkpoint
Explain in your own words: what does HTML do, and what does a browser do?

---

## Week 2 — Organising content

### Try it
1. Add a `<header>` with your portfolio title.
2. Add a `<nav>` section.
3. Add a `<main>` section.
4. Inside main, create two `<section>` elements.
5. Add a `<footer>`.

### Challenge
Create `about.html` with:
- A short biography
- Three interests
- Two skills you are developing
- One goal for this year

### Checkpoint
Write down what each of these elements is used for: `header`, `nav`, `main`, `section`, `footer`.

---

## Week 3 — Links and images

### Try it
1. Add a link from `index.html` to `about.html`.
2. Add a Projects link.
3. Create an `assets` folder.
4. Add one approved image to the folder.
5. Display it using an `<img>` element and meaningful `alt` text.

### Challenge
Create two project previews with a title, description, image and link.

### Checkpoint
What is the difference between `src` and `href`?

---

## Week 4 — First CSS

### Try it
1. Create `css/style.css`.
2. Link it from your HTML.
3. Change the page background.
4. Change the body font.
5. Change the main heading colour.

### Challenge
Create a `.highlight` class and use it on two different elements.

### Checkpoint
Label the selector, property and value in this rule:
```css
h1 {
  color: purple;
}
```

---

## Week 5 — Your design theme

### Try it
1. Choose a primary colour.
2. Choose a background colour.
3. Choose an accent colour.
4. Choose a font.
5. Apply the choices to all pages.

### Challenge
Use CSS variables for your colours. Add a consistent style for links and buttons.

### Checkpoint
Why is it useful to use the same colours and fonts throughout a website?

---

## Week 6 — Box Model

### Try it
1. Create a `.card` class.
2. Add padding.
3. Add a border.
4. Add a margin.
5. Add rounded corners.

### Challenge
Create a centred content container with a maximum width. Use the same card style for your About and Projects sections.

### Checkpoint
Draw and label the CSS Box Model: content, padding, border and margin.

---

## Week 7 — Flexbox and Grid

### Try it
1. Use Flexbox to line up your navigation links.
2. Use CSS Grid for your project gallery.
3. Add a gap between cards.
4. Make the gallery display three columns on a wide screen.

### Challenge
Use `minmax()` or `auto-fit` to create a grid that adjusts more naturally.

### Checkpoint
Give one example of when you would use Flexbox and one example of when you would use Grid.

---

## Week 8 — Multiple pages

### Try it
Create and connect:
- `index.html`
- `about.html`
- `projects.html`
- `contact.html`

Each page should have the same navigation and footer.

### Challenge
Add a separate project detail page. Include the project's goal, process, tools and outcome.

### Checkpoint
Test every navigation link. Record any broken links and how you fixed them.

---

## Week 9 — Interactions and polish

### Try it
1. Add a hover style to links.
2. Add a hover style to buttons.
3. Add a subtle transition.
4. Add a visible keyboard focus style.

### Challenge
Add a subtle card hover effect without making the page distracting.

### Checkpoint
Why should interactive elements have both hover and keyboard-focus styles?

---

## Week 10 — Responsive design

### Try it
1. Make images responsive.
2. Add a media query at 700px.
3. Make the project grid one column on small screens.
4. Test at mobile, tablet and desktop widths.

### Challenge
Find and fix three layout problems at narrow screen widths.

### Checkpoint
What is a breakpoint? Why does a website need to adapt to different screens?

---

## Week 11 — Final build

### Try it
1. Complete all four pages.
2. Add at least three projects.
3. Check all links and images.
4. Check spelling and readability.
5. Ask your partner to test your site.

### Challenge
Add an original feature and explain how you made it.

### Checkpoint
List two improvements you made after testing or feedback.

---

## Week 12 — Publish and present

### Try it
1. Check that `index.html` is in the repository root.
2. Commit your latest changes.
3. Enable GitHub Pages.
4. Open the published website.
5. Test all pages and links.

### Presentation
Give a 3–5 minute presentation:
- Introduce your portfolio.
- Show your favourite page.
- Explain one HTML feature.
- Explain one CSS feature.
- Describe a challenge you solved.
- Share one future improvement.

### Final reflection
Write 150–250 words:
- What did you learn?
- What are you most proud of?
- What was challenging?
- What would you build next?
